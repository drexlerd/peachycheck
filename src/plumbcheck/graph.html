Standards map

How to read this map
  • Guidelines lists every guideline by language, Metrics how the work is judged, Graph how languages, tools, loops, metrics and literature connect.
  • The filters narrow every view; the number after a value counts the guidelines it would leave. Active filters show as chips: × removes one, Clear all removes all. The tabs count what remains.
  • Select a row or a node (click, Enter or Space) to see its details in the panel; names there are links.
  • Every loop that works on a language's files receives all its guidelines. They bind, except advisory ones, which are recommendations.
  • Checked by names the tool that enforces a guideline after every reply, or gate: metric when a gate metric enforces it; a guideline without either only a reviewer can check.
  • Loop view shows, for one loop and the files of one language, the Standards section of its prompt and the metrics that judge its work.
  • In the graph, double-click a box or press Open to go inside; the trail above goes back up; ×48 bundles 48 connections.
